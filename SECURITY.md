# Security

## How your data is handled

- **Your API key** is stored locally in the browser's extension storage on your own device. It is sent only to the AI provider you select, as part of making requests. It is never sent anywhere else.
- **Your catalog** (titles, descriptions, thumbnails) stays in your browser until you choose to export it as an HTML or CSV file.
- The extension only reads your **own** saved posts in your **own** logged-in Instagram session.

## Keep your key safe

- Never paste your API key into a public place (issues, pull requests, screenshots, chats).
- If you share the extension with someone, they should use **their own** key, not yours.
- If you think your key has been exposed, revoke it in your provider's dashboard and create a new one.

## Reporting a vulnerability

If you find a security issue, please **do not** open a public issue with the details. Instead, contact the maintainer privately (for example, via a GitHub private message or the email on the maintainer's profile) so it can be addressed before disclosure.
